## Deployment

- Rename the default Compose configuration to `docker-compose.yml`.
- Pull `yexca/harbor:latest` from Docker Hub by default for standalone production
  deployment, without requiring a source checkout or local build.
- Add `docker-compose.dev.yml` for local builds and point Makefile Compose
  commands at the development configuration.
- Bind-mount `./data` in both Compose configurations and document host directory
  permissions, backups, and migration from named volumes.

## Upgrade Notes

The default Compose mount now uses the host's `./data` directory instead of a
Docker-managed volume. Copy the existing `services.json` from the old container
to `./data/services.json` before recreating it, and ensure UID/GID `10001:10001`
can read and write the directory and file on Linux. Preserve the old volume
until the restored collection has been verified.

Production and development instances must use separate host data directories;
changing only the Compose project name does not isolate a bind mount. The JSON
data format and default port `7750` are unchanged.
