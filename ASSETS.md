# Visual assets

## Mountain wallpaper

- File: `server/web/wallpaper.jpg`
- Created with the built-in OpenAI image generation tool for this project.
- The generated PNG was encoded as JPEG at quality 84 for local delivery. The composition was not changed.
- Served from the embedded application assets; no remote image service is used.

Generation prompt:

> Use case: photorealistic-natural. Asset type: full-screen wallpaper for a minimalist personal browser start page. Create an original landscape photograph of layered alpine mountain ridges descending into a still misty lake at blue hour, distant pale mountain silhouettes and soft atmospheric haze, deep slate blue and muted teal foreground, very subtle warm peach light near the horizon. Wide 16:9 landscape composition. Upper 45 percent is a clean softly shaded blue-gray sky with generous quiet negative space for a white clock; mountains cluster toward lower sides, center stays low-detail to support frosted glass application cards. Natural photographic detail, serene, premium desktop wallpaper, softly diffused evening light, restrained colors. No people, no buildings, no UI, no text, no numbers, no logos, no watermarks. Generate the landscape image alone.

## Other visuals

- `docs/assets/harbor-showcase.png` is a README illustration created with the
  built-in OpenAI image generation tool. It depicts fictional services and a
  composed All apps inset, rather than an exact application screenshot.
  The generation prompt is recorded in [the showcase notes](docs/assets/harbor-showcase.md).

The spacious clock-first composition was informed by [Lime Start Page](https://intro.limestart.page/). No Lime Start Page code, screenshots, logos, or wallpaper assets are included.
